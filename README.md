# QR Code Generator

A simple and classy QR Code Generator built with HTML, CSS, JavaScript, and jQuery.

## Features

- Generate QR codes from any URL
- Automatically adds `https://` if needed
- Download the generated QR code as a PNG
- Clean and responsive frontend
- Simple and easy-to-use interface

## Technologies Used

- HTML5
- CSS3
- JavaScript
- jQuery
- QRCode.js
- Node.js
- npm

## How to Run

1. Clone the repository.

2. Install the dependencies:

```bash
npm install
```

3. Run the Node.js file:

```bash
node index.js
```

For the frontend, open:

```text
frontend/index.html
```

in your browser.

## How It Works

Enter a URL into the input field and click **Generate**. The application creates a QR code that can be scanned using a phone camera.
